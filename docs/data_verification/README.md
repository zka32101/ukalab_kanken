# 漢字データの確認記録

確認日: 2026-10-03

対象は、級別の配当漢字（`lib/data/level_kanji_data.dart`）、読みと用例の簡易辞書（`lib/data/kanji_info_data.dart`）、問題データ（`scripts/seed-kanji-questions.js`）。

## 照合に使った資料

| 資料 | 用途 | 備考 |
|---|---|---|
| 小学校学習指導要領 別表「学年別漢字配当表」（文部科学省告示・2017年告示） | 10級〜5級の配当漢字（第1〜6学年 = 計1,026字） | 告示は著作権の対象外（著作権法13条）。照合用の表は `test/fixtures/official_grades.json`（公開されている転記から取り、各学年の字数 80/160/200/202/193/191 が告示と一致することを確認） |
| 常用漢字表（2010年内閣告示）の読み | 読みの確認 | Unicode の Unihan（`kJapaneseOn` / `kJapaneseKun` / `kJoyoKanji`）と、常用漢字表の読みで確認 |

注意: Unihan の `kGradeLevel` は日本ではなく**香港**の学年なので使っていない。

4級・3級の配当は漢検の級別漢字表に基づくもので、公的な告示ではない。ここでは「常用漢字であること」「小学校の配当漢字と重複しないこと」「4級と3級で重複しないこと」だけを確認した。

## 結果

| 項目 | 結果 |
|---|---|
| 10級〜5級の配当漢字 | 公式の学年別漢字配当表と**過不足なく一致**（1,026字） |
| 4級・3級が常用漢字か | 全字が常用漢字 |
| 4級・3級と小学校配当の重複 | **4級の井・沖・香、3級の岐が重複**。2020年度から都道府県名の20字が小学4年の配当（7級）に加わったため。4級313字・3級284字に修正（漢検の現行の字数と一致） |
| 読みの辞書（1,026字） | 1,011字は Unihan と一致。残り15件（四=よん、生=い（きる）・なま、好=す（き）、側=がわ ほか）は常用漢字表にある正当な読みで、誤りなし |
| 用例に見出しの字が含まれるか | 息の用例「深呼吸」に「息」がない → 「息（いき）」に修正 |
| 4級・3級の読み（601字） | 薪=「まき」は常用漢字表にない読み（シン・たきぎ）→ 「たきぎ」に修正。擦=す（れる）、脅=おびや（かす）は正当 |
| 問題の構造 | 級ごとの問題数が配当漢字の数と一致。選択肢は4つ・重複なし・正解を含む。**4級・3級の他の問題の選択肢に、削除した字（井・沖・香・岐）が19か所残っていたので、同じ級の別の字に差し替えた**（正解は変更なし） |

## 回帰テスト

`test/level_kanji_data_test.dart` が上記を検査する（配当表との一致、重複、問題数、選択肢、用例、薪の読み）。

## 本番データの扱い（要対応）

`scripts/seed-kanji-questions.js` は `questions/{id}` を上書き（set）するだけで、**削除はしない**。次のドキュメントは Firestore に残るので、シード再実行のあと手動で削除する必要がある。

- `LEVEL_4-井`、`LEVEL_4-沖`、`LEVEL_4-香`、`LEVEL_3-岐`

シードを再実行すると、修正した読み・用例・選択肢が反映される。

## 範囲外（確認していないもの）

- `export_data/` の JSONL は旧版で、級の割り当てが配当表と食い違う（例: 「時」が10級）。現行のシード（`scripts/seed-kanji-questions.js`）には使われていない。取り込みに使わないこと
- 模擬試験（`scripts/seed-exam-questions*.js`）の問題内容
- 書き順データ（`stroke_order_sample_data.dart`）、部首・熟語構成データ
- 用例の語そのものの妥当性（用例が学年に合うか、など）

## 準2級・2級（513字・要照合）

常用漢字2,136字のうち、3級までの1,623字を除いた513字を、準2級（328字）と2級（185字）に分けて追加した（画面の級は `LEVEL_2_PRE` / `LEVEL_2`）。

- **確認できたこと**: 513字すべてが常用漢字であること。3級までの字と重複しないこと。合計が2,136字になること（`test/level_kanji_data_test.dart`）。読みは Unihan（`kJapaneseOn` / `kJapaneseKun`）に載っていることを確認し、載っていない読みは常用漢字表の読みか個別に確認した（冥=ミョウ、刹=セツ、爪=つま、棟=むな など）。常用漢字表にない読みは入れていない
- **振り分けの照合（2026-10-14）**: 日本漢字能力検定協会の級別漢字表（2020年2月発表, https://www.kanken.or.jp/kanken/outline/data/outline_degree_national_list20200217.pdf の準2級328字・2級185字）と、漢字辞典オンライン（kanji.jitenon.jp/cat/kyu02j, kyu02）・書き順サイト kakijun.jp の一覧で照合し、準2級と2級で**70字ずつ入れ替わっていた**のを修正した（嵐・咽・怨・牙・瓦・潰・崖・蓋・柿・釜・鎌・韓・亀・嗅・僅・憬・隙・桁・拳・鍵・股・虎・喉・駒・頃・痕・餌・嫉・袖・拭・尻・芯・腎・戚・腺・狙などが2級。逆に且・丙・俸・劾・唆・嗣・嚇・塑・奔・娠・嫡などが準2級）。シードの問題も級ごとに作り直した。
- **本番データの扱い**: 級が変わった140字の旧ドキュメント（`LEVEL_2_PRE-嵐` など、移動した字の旧ID）はシード再実行では消えない。再実行後に手動で削除すること
- 公式の表が手に入ったら、`lib/data/level_kanji_data.dart` の `LEVEL_2_PRE` / `LEVEL_2` の文字列を差し替え、`scripts/seed-kanji-questions.js` を再生成する
- 模擬試験（`examQuestions`）にはまだ準2級・2級のデータがない。準2級は整数の級番号にできないため、模擬試験側では 25 として扱い、問題が無いときの表示になる
- 書き順データは4級・3級と同様に無い

## 準1級（941字・要照合）

常用漢字の外にある準1級の配当漢字を追加した（画面の級は `LEVEL_1_PRE`）。

- **字と読みの出典**: 漢字辞典オンライン（kanji.jitenon.jp）の「漢検準1級の配当漢字一覧」（掲載は942字）。ここから字とその読みをそのまま取った。公式の級別漢字表（日本漢字能力検定協会）とは照合していない。掲載の942字のうち、互換漢字の「簾」（U+F9A6）は通常の「簾」（U+7C3E）と同じ字なので1字として数え、941字にした
- **用例**: 上記の一覧には用例がないため、編集者が付けた。実在の語を選んだつもりだが、字が珍しいものは「その字を含む語」を見つけにくく、「字（読み）」だけの用例になっているものがある。読みは一覧にある読みと合うことを機械で確認した
- **確認できたこと**: 常用漢字2,136字と重複しないこと、準1級内で重複しないこと、各字に読みと用例があること、選択肢が同じ級の字であること（`test/`）
- **確認できていないこと**: 公式の準1級配当漢字表との照合、読みが漢検の出題読みと一致するか、用例の語としての適切さ
- 模擬試験・書き順のデータは準1級にもない。模擬試験の級番号は準1級を 15 として扱い、問題が無いときの表示になる

## 1級（2,797字・要照合・用例は864字のみ）

準1級までの字を除いた1級の配当漢字を追加した（画面の級は `LEVEL_1`）。

- **字と読みの出典**: 漢字辞典オンライン（kanji.jitenon.jp）の「漢検1級の配当漢字一覧」（掲載2,797字）。字とその読みをそのまま取った。公式の級別漢字表（日本漢字能力検定協会）とは照合していない。互換漢字の「屮」（部首の字）は通常の「屮」（U+5C6E）に直した。画像で表示されている4字（𣶏・𩶗・𫒼・𬵪）は字形が分かる字として含めた
- **用例は864字にだけ付けた**: 1級の字は人名・古典にしか出ない字が多く、実在の語を確実に挙げられない字が多いため、確実なものだけに付けた（残り1,933字は読みだけで、画面に「使い方の例」が出ない）。用例の読みが一覧にある読みと合うことは機械で確認した。語としての適切さは未確認
- **確認できたこと**: 準1級までの字と重複しないこと、1級内で重複しないこと、各字に読みがあること、読みの形が正しいこと、選択肢が同じ級の字であること（`test/`）
- **確認できていないこと**: 公式の1級配当漢字表との照合、読みが漢検の出題読みと一致するか
- 模擬試験・書き順のデータは1級にもない。1級は級番号 1 で模擬試験の問題を探すので、問題が無いときの表示になる

## 画数（2026-10-15）

- **データ**: `lib/data/kanji_stroke_count_data.dart`（`kanjiStrokeCount(String)` → `int?`）。生成は `scripts/generate_kanji_stroke_count.py`（再現手順はスクリプト冒頭）
- **出典**: KANJIDIC2（EDRDG, database_version 2026-288）の `stroke_count`。CC BY-SA 4.0。出典の明示と https://www.edrdg.org/edrdg/licence.html へのリンクが必要で、設定画面の「出典・ライセンス」に表示している
- **採用方針**: 画数が1つに定まる字だけを採用（**5,478字**）。KANJIDIC2 に画数が無い字（25字）と、画数が複数値の字（371字）は自動採用せず、データには入れていない（`kanjiStrokeCount` は null）。一覧は [stroke_count_review.md](stroke_count_review.md)
- **Unihan の kTotalStrokes は使わない**: 日本の数え方と合わない字があるため
- **書き順データとの関係**: `StrokeOrderData.strokeCount`（= 線の数）は変えていない。画数の表示（書き順アニメーションの「全N画」）だけ、画数データがあればそちらを使う。10級〜5級1,026字のうち、画数データのある994字は線数と**全字一致**（慣も14線＝14画で、不一致なし）。複数値のため画数が未設定の32字（通・近・遠・道 ほか、しんにょうの字など）も、線数はKANJIDIC2の先頭値と一致している。画数の範囲は1〜33（最大は麤の33画）
- **要確認**: 要確認396字は、公的な資料（漢検の漢字表・辞典など）で確認してから手で追加する。`test/kanji_stroke_count_data_test.dart` が「未設定の字 = 要確認一覧」を検査する
- **ライセンスの影響（未確認）**: KANJIDIC2 は CC BY-SA 4.0（継承条件あり）。アプリ全体への影響は法的判断が未確認なので、ストア配布前に要確認
- **範囲外**: 意味・用例（AI生成文を公的データ扱いにしない）

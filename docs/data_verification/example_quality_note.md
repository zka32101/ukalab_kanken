## 「読みを網羅しない」の見方(目安であり誤りの数ではない)

判定は「各読みの語幹が、いずれかの用例のかっこ内の読みに含まれるか」という単純な文字列照合。次の理由で**過検出**がある。

- 連濁・音便で形が変わる(例: 馬=うま → 用例は「馬車（ばしゃ）」)
- 送り仮名つきの訓の語幹と用例の読みが一致しない書き方(例: 計=はか（る）)
- 漢字表記の特別な読み(例: 今日（きょう）)

一方、本当に用例が無い読みもある。たとえば一=イツ、十=ジッ、生=ショウ・なま、青=ショウ、白=ビャク、女=ニョ、下=さ（げる）・くだ（る）など、**表の読みのうち使用頻度の低い読み**に用例が無い傾向がある。常用漢字表の読みを全部載せるか、よく使う読みだけで良いかは方針次第なので、別PRで用例を照合する際に決める。
